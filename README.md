## Mahsum Aktaş

Operations manager at [oBilet](https://obilet.com) by day, building AI systems by night.

I run a team of 8 managing 400+ bus companies. I also build the tools we use — including an AI operations assistant that runs 24/7 on a Raspberry Pi.

### What I'm building

- **[Osistan](https://mahsumaktas.com/projects/osistan)** — AI operations assistant. 3-layer architecture, 39K email embeddings, serves the team via Slack. Runs on a Raspberry Pi 5, ~$40/month.
- **[Jazari](https://mahsumaktas.com/projects/jazari)** — Turkish LLM ecosystem. Fine-tuned 4B model on [HuggingFace](https://huggingface.co/mahsum/jazari-4b-sft-tr), voice-first life coach app, Android app in closed beta.
- **[Treliq](https://github.com/mahsumaktas/treliq)** — AI-powered PR triage for open-source maintainers. 428 tests. [Posted on Hacker News](https://news.ycombinator.com/item?id=47073344).
- **[Qragy](https://github.com/mahsumaktas/qragy)** — Self-hosted RAG chatbot, runs on a Raspberry Pi.
